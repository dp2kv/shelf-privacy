# Shelf — Privacy Policy

This repository exists for one reason: to publish the privacy policy for the
**Shelf** Android app (`com.shelf.filemanager`) at a public URL, which Google
Play requires on the store listing.

**Published at:** https://dp2kv.github.io/shelf-privacy/

It holds no application source code. The app itself lives in a private
repository.

## Contents

| File | Purpose |
| --- | --- |
| `index.html` | The privacy policy, self-contained — no external assets |
| `.nojekyll` | Serves the file as-is, bypassing Jekyll processing |

## Updating the policy

The policy is maintained alongside the app as `android/PRIVACY.md` in the
private repository, and `index.html` here is the published rendering of it.
When the policy changes, update both so they do not drift apart, and revise the
"Last updated" date shown at the top of the page.
