Privacy Policy for Shelf

Last updated: 28 October 2026

Shelf is a file manager and local-network file transfer app for Android (package com.shelf.filemanager).

The short version: Shelf has no servers, no accounts and no analytics. Nothing you do in this app is sent to the developer, because there is nowhere for it to be sent. Every piece of data described below stays on your device, or travels directly to another device you explicitly choose on your own network.

1. Information the developer collects

None.

Shelf contains no analytics SDK, no advertising SDK, no crash reporting service and no telemetry of any kind. It does not create an account, ask for an email address, or assign you an identifier.

The app's source contains no network address belonging to the developer. It cannot phone home, because it has no home to phone.

2. Information stored on your device

Shelf keeps the following in its own private storage, readable only by Shelf and removed completely when you uninstall it:

WhatWhyWhere
Display preferences — view style, row density, sort order, show hidden/system files, show extensions, photo grid So the app opens the way you left it App-private settings
Bookmarked folders So your shortcuts persist App-private settings
Recycle bin settings — whether it is on, how many days to keep So deletion behaves as you configured App-private settings
Server configuration — the sharing settings you choose So you do not reconfigure on every launch App-private settings
Transfer history — for each transfer: the other device's name or local address, file name, file size, start and finish time, outcome, and the file's location on your device So you can see what was sent or received, reopen a file, or resend it App-private internal storage
Vault contents, plus the salt and hash used to verify your vault passphrase So vault files stay encrypted at rest App-private internal storage

Your vault's encryption key is held in the Android Keystore, a hardware-backed area managed by the operating system. The app never stores your passphrase itself, only a salted hash used to check it.

You can erase all of it at any time: clear the app's history from within the app, or use Settings → Apps → Shelf → Storage → Clear data, or uninstall the app.

3. Your files

Shelf reads and writes files on your device because that is what a file manager does. Browsing, copying, moving, renaming, compressing, hashing, finding duplicates, analysing storage use and recovering deleted items all happen entirely on your device.

Your files are never uploaded anywhere. No file content, file name, or directory listing is transmitted to the developer or any third party.

4. Network use

Shelf transfers files over your local network only — typically your home or office Wi-Fi.

  • Transfers go directly between your device and another device you choose, by scanning its code or entering its local address. The data does not pass through any intermediate or cloud server.
  • The developer operates no server of any kind for this app.
  • When you turn sharing on, Shelf runs a server on your own device so other devices on the same network can reach the folders you selected. It stops when you turn it off.
Please note: transfers on the local network use plain HTTP and FTP and are not encrypted in transit. Anyone else on the same network who is actively watching traffic could potentially observe them.

Shelf does protect access: a direct transfer can be gated behind a one-time, expiring offer that the receiving device must authorise with a PIN, so an uninvited device on the same network cannot simply help itself. That is access control, not encryption — it decides who may fetch a file, but it does not scramble the bytes on the wire.

Use Shelf's sharing features on networks you trust, and turn sharing off when you are finished. This is disclosed here deliberately so you can make an informed choice.

5. Permissions, and why each is needed

PermissionWhy Shelf needs it
All files access (MANAGE_EXTERNAL_STORAGE) Core file manager functions that must see the whole storage volume: searching your device, finding duplicate files, analysing what is using your space, and the recycle bin, which stores deleted items on the same volume so that deleting is instant and does not need a second copy of the file.
Internet, network state, Wi-Fi state, local network access To send and receive files over your local network, and to show you the correct address and connection status.
Notifications To show transfer progress and to tell you when sharing is switched on.
Foreground service (data sync) So a transfer in progress is not killed by the system when you switch apps.
Keep awake (WAKE_LOCK) So the screen turning off does not interrupt a transfer that is running.
Read/write external storage (older Android versions only) The equivalent of all files access on Android 9 and below.

Shelf does not request access to your contacts, camera roll metadata, microphone, location, call logs, or messages.

6. Third parties

Shelf shares data with no third party, because it collects none.

The app is built with open-source libraries (AndroidX, Jetpack Compose, OkHttp, Ktor, ZXing, Apache Commons Net). These run entirely on your device and none of them transmit data to their authors or to the developer.

7. Children

Shelf is a general-purpose utility. It does not knowingly collect information from anyone, of any age, because it does not collect information at all.
